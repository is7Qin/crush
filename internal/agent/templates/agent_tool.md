Launch a sub-agent that performs the task in its own session. Every delegation is asynchronous: the call returns a durable task id as soon as the task is accepted, never the child's result. The child keeps running after this turn ends; inspect it with agent_status and agent_output (by task id), send it follow-up messages with agent_message (queued to its FIFO mailbox, never waits for the child), stop it with agent_cancel, or continue the conversation with a new call_agent that passes task_id for one of your own terminal tasks (the retained child session gets a fresh attempt under the current profile and model policy). Children run with full ordinary capabilities (bash, edit, write, view, grep, and the rest), minus delegation tools: children never delegate. Set profile to run the task under another agent profile: the Crush base agent profiles (coder, task; task is read-only search: glob, grep, ls, view), the OMO-native roster (sisyphus, hephaestus, oracle, librarian, explore, multimodal-looker, prometheus, metis, momus, atlas, sisyphus-junior: coding roles carry full ordinary capabilities, research roles are read-only), or a profile configured via the agents config key, which may override the model, system prompt, and tool policy of any built-in of the same name. Set model to an exact provider/model override for the child; an unavailable model fails without fallback.
